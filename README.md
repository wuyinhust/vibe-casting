# Vibe Casting

**Vibe Casting（氛围选角）**是一套用于创造长期可运营 AI 虚拟人物的方法型 Skill（技能）。

它解决的不是“怎么生成一张漂亮人像”，而是：

> 怎么从零创造一个能被持续拍摄、持续换装、持续写故事、持续生成视频，而且始终还是“这个人”的原创虚拟角色。

这套方法不提供任何现成角色模板，也不绑定某一种脸、发型、服装、世界观或摄影风格。它只复用**角色生成方法**。

---

## 核心流程

```text
找对标
  ↓
灵感迸发
  ↓
视觉迭代
  ↓
人设确认
  ↓
身份锚点
  ↓
服装体系
  ↓
角色卡生成
  ↓
世界观生成
  ↓
视觉统一
  ↓
回归验证
```

这 10 个阶段分别解决不同问题：

| 阶段 | 解决的问题 |
|---|---|
| 找对标 | 什么样的人物已经被证明能成立，为什么成立 |
| 灵感迸发 | 如何把多个气质来源拆散后重新组合，而不是复制 |
| 视觉迭代 | 这个人是否越来越像“她自己”，而不只是越来越漂亮 |
| 人设确认 | 她如何行动、说话、社交、发呆、被点亮 |
| 身份锚点 | 换衣服、换场景、换镜头后，凭什么还是同一个人 |
| 服装体系 | 不是设计一套制服，而是建立“这个人会买什么衣服”的规则 |
| 角色卡生成 | 把人物转成可供图像与视频模型稳定调用的控制资产 |
| 世界观生成 | 给人物建立可持续产生日常故事的舞台，而不是先写宏大设定 |
| 视觉统一 | 让人物、世界、图片、视频属于同一个摄影世界 |
| 回归验证 | 随机换服装、场景、时间和动作后，验证角色是否仍然稳定 |

## 设计原则

### 1. 复用方法，不复用人物

禁止把任何已完成角色的这些内容默认继承给新角色：

- 脸
- 发型
- 发色
- 固定道具
- 性格反差
- 内容母题
- 服装体系
- 世界观
- 摄影风格

新角色只继承流程和质量门槛。

### 2. 找对标不是找复制对象

对标只用于提取：

- 人物机制
- 气质机制
- 内容机制
- 摄影机制
- 传播机制

具体标志性道具、剧情、口头禅、发型、服装和构图不得直接照搬。

### 3. 先把“人”做对，再扩世界

正确顺序是：

```text
脸与年龄稳定
→ 人格成立
→ 身份锚点稳定
→ 衣柜成立
→ 角色卡成立
→ 世界成立
→ 摄影与视频统一
```

不要在人物还没稳定时先写大量世界观、配角和故事线。

### 4. 漂亮不是完成标准

每轮视觉迭代最重要的问题不是：

> “这张好不好看？”

而是：

> “这个人越来越像她自己了吗？”

## 如何使用

当用户提出类似请求时启用本 Skill：

- “帮我创造一个 AI 虚拟人物”
- “帮我做一个长期运营的虚拟角色”
- “这个角色还不够稳定，继续迭代”
- “帮我把这个人物做成角色卡”
- “帮我建立她的衣柜、世界观、摄影规范”
- “为什么我换一套衣服之后就不像同一个人了”

Skill 会根据当前完成度进入对应阶段，而不是每次从头开始。

如果用户已经提供了参考图或已经完成部分阶段，直接从现有资产继续，不强制重复前置步骤。

---

## 最终交付标准

一个角色只有在以下条件全部通过后，才建议标记为 `v1.0`：

- 年龄感稳定
- 脸稳定
- 发型稳定
- 动态状态稳定
- 核心反差成立
- 人格成立
- 身份锚点明确
- 衣柜体系成立
- 主角色卡完成
- 三视图完成
- 世界观成立
- 摄影协议成立
- 视频测试完成
- 换装后仍然是同一个人
- 换场景后仍然是同一个人
- 没有明显复制对标角色的具体符号

详见 `docs/quality-gates.md`。

---

## 一句话

> Vibe Casting 不是“生一个角色”，而是通过连续选角、定妆、试拍、建档与回归测试，让一个原本模糊的人逐渐成为一个真正稳定的人物。
