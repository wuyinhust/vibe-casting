## 关键证据

- 约 45 岁的中英文查询使用一致的年龄上下界，显式年龄条件与文本条件取交集。个人用途筛选不能覆盖文本中的商业使用要求。
- 服装条件与完整角色包必须由同一套可见造型满足；私人造型不贡献公共目录的完整度。
- 已公开人物的人设修订保存在新的私人身份版本中。没有对应展示图的新身份不能沿用旧封面直接发布。
- 并发冻结不会超扣；失败与成功结算均幂等；重复支付通知只入账一次。
- 模拟提供方在第二张候选图中断：整阶段积分解冻，第一张部分结果保持私人，不产生角色包。此项是依赖注入测试，不是真实 OpenAI API 验证。
- 商务消息和图片附件对其他账号不可读；个人令牌不能访问聊天、充值或后台。
- ZIP 中的 PNG 不做重复压缩，减少批量下载对同时进行的目录请求的阻塞。
