# AVIBE 界面与功能验收基准

2026-10-01 用户确认以当前 `avibe.net` / `preview.avibe.net` 的公开预览视觉为准，并要求保留线上版本，同时扩充 Next.js 功能。这个视觉基准的源码是 `public-preview/index.html` 与 `public-preview/preview.css`。Next.js 首页直接使用同一份 CSS；上线前必须检查两端视觉差异，当前线上文件不得因功能开发而覆盖。

## 设计约束

- 白底、226px 固定侧栏、90px 顶栏、细分隔线和充分留白；小于 700px 时收起侧栏。
- 标志使用 Manrope 粗字与渐变星号；正文使用 DM Sans。主要文字 `#191919`，弱化文字为中性灰，强调色由橙、粉、紫渐变提供。
- 首页保留状态胶囊、主视觉、三张方法卡片和 Skill 区块。功能页延续侧栏、顶栏、卡片、圆角与克制的渐变点缀。中文与英文都需可用。
- 不把本地演示角色图或角色包发布到公共目录；功能页展示内容只由该环境数据库中的可见、已审核、获授权记录决定。

## 页面与状态清单

| URL               | 页面     | 需验收的状态                                       |
| ----------------- | -------- | -------------------------------------------------- |
| `/`               | 公开首页 | 中英、桌面、手机、进入角色发现、Skill 链接         |
| `/discover`       | 角色发现 | 列表、关键词、硬条件筛选、空结果、加载与错误       |
| `/characters/:id` | 角色详情 | 直达、身份／造型／角色包、授权、未登录、关闭与返回 |
| `/boards`         | 选角板   | 空白、创建、角色分配、导出、权限                   |
| `/studio`         | 工作室   | 草稿、生成报价、缺少模型配置时的禁用态、任务结果   |
| `/messages`       | 消息     | 空白、会话、发送、未读、附件、权限与恢复           |
| `/account`        | 账户     | 登录、资料、积分、授权、令牌、退出                 |
| `/skill`          | Skill    | 介绍、包下载与使用说明                             |
| `/admin`          | 运营     | 仅授权运营账号可进入；审核、价格、会话分配         |

功能页面共用 `src/components/platform.tsx` 的路由状态；业务数据来自 `/api/v1` 和 PostgreSQL。浏览器前进后退应恢复当前功能页，角色详情应有可直达 URL。状态清单中的后端外部服务状态，仍须在独立预发布环境实测。

## 本地证据与发布边界

`npm run build`、`npm run typecheck`、`npm test`、`npm run db:check` 和 `npm run test:e2e` 为代码、本地数据库和浏览器证据。Playwright 保存桌面与手机首页及功能页截图到 `test-results/`，这些本地演示截图含仅供本地评估的虚构角色图片，不得作为线上素材发布。

正式数据库要执行四个迁移，并在 `AVIBE_MODE=live` 环境运行 `npm run db:check`；该检查覆盖 30 张业务表、全部 RLS 开关和私有存储桶。它不代替双账号隔离、邮箱 OTP、实时通知、私有下载、Worker、模型与支付服务的真实部署验收。线上公开预览和旧站 `a.avibe.net` 在此之前维持当前绑定。
