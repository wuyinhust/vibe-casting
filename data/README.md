# Demo talent data

The eight fictional demo records used by the website are defined in `apps/avibe-web/data/demo-characters.json`; `apps/avibe-web/src/lib/seed.ts` loads them into the local demo database. The relational schema is in `apps/avibe-web/supabase/migrations/`. The example images are evaluation fixtures, not production listings. Lin Yue's downloadable example package is for local product evaluation only; the remaining records are showcase-only.

Private creator-account prospecting rows, source snapshots and internal research notes are intentionally excluded from this repository. An account lead is not a character asset and does not carry image, download, commercial or collaboration rights.
