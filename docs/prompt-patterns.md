# Vibe Casting 提示词模式

这些不是固定角色提示词，而是阶段化提示结构。每次使用时应填入当前角色自己的身份锚点、服装体系、世界规则和视觉协议。

## 1. 对标研究提示结构

```text
研究这些参考人物 / 账号，不要复制具体外观或标志性元素。
请分别拆解：
1. 人物本体
2. 人格机制
3. 内容机制
4. 摄影机制
5. 传播机制
最后输出：
- 可以抽象继承的设计原则
- 必须避开的具体符号
```

## 2. 三候选方向提示结构

```text
基于已完成的对标拆解，不直接复刻任何参考人物。
将灵感拆成：五官方向 / 情绪方向 / 主角感方向。
生成 A、B、C 三个彼此独立的原创人物方向。
每个方向只强调一个主要差异，并保持其他条件尽量一致，方便比较。
```

## 3. 身份迭代提示结构

```text
当前唯一目标：修正【年龄 / 脸 / 发型 / 表情 / 身体比例】。
严格保留已经确认的其他身份锚点，不重新设计人物。
不要额外改变服装、场景、光线和整体风格。
```

## 4. 三视图提示结构

```text
基于身份参考生成角色设计三视图：
左：正面近景胸像
中：正面全身标准站姿
右：背面全身标准站姿

要求：
- 纯色干净背景
- 同一人物、同一年龄、同一身体比例
- 左侧清晰展示身份特征
- 中间与右侧优先展示结构一致性
- 头发长度、肩宽、腰臀比例和服装正背面必须一致
- 禁止文字、水印、复杂场景
```

## 5. 换装提示结构

```text
人物身份优先级高于服装。
严格保持：脸型、五官比例、年龄感、骨架、身体比例、发型轮廓、表情气质。
仅根据服装参考替换穿着。
服装遵守既定衣柜规则，而不是把人物改造成服装参考中的模特。
```

## 6. 世界观提示结构

```text
基于已经稳定的人物性格创建一个有限边界的生活世界。
世界必须服务人物，而不是压过人物。
输出：
- 世界一句话
- 5～8 个固定地点
- 4～8 个固定居民
- 异常尺度
- 10 个无需宏大剧情也能成立的日常事件
```

## 7. 视觉统一提示结构

```text
所有画面必须服从同一摄影协议：
- 相机体系：___
- 焦段感：___
- 日间色彩：___
- 夜间色彩：___
- 高光：___
- 阴影：___
- 颗粒：___
- 白平衡：___
- 肤色：___

禁止只写“电影感”或“胶片感”，必须通过具体画面行为体现。
```

## 8. 视频提示结构

```text
身份优先级：脸 > 发型 > 年龄 > 身材 > 气质 > 衣服 > 场景。

场景：___
动作：___
默认状态：___
激活状态：___
世界轻微偏差：___
摄影协议：___

视频应像真实生活被镜头碰巧捕捉，而不是角色持续对镜头表演。
```

## 9. 回归验证提示结构

```text
在不改变一级身份锚点的前提下，随机改变：
- 服装
- 场景
- 时间
- 表情
- 动作

目标不是产出最好看的画面，而是验证：
“一个不了解项目的人，能否稳定判断所有结果都是同一个角色？”
```
