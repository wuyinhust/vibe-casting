# Vibe Casting 质量门槛

角色达到 `v1.0` 前，以下项目全部需要通过。

## 对标与原创性
- [ ] 已完成对标研究
- [ ] 已提取抽象机制
- [ ] 已列出禁止直接复制的具体符号
- [ ] 无明显复刻某个参考角色的道具、剧情、口头禅、发型或固定构图

## 人物身份
- [ ] 年龄感稳定
- [ ] 脸型稳定
- [ ] 五官比例稳定
- [ ] 发型轮廓稳定
- [ ] 身体比例稳定
- [ ] 动态状态稳定
- [ ] 不依赖固定服装才能认出角色

## 人格
- [ ] 四层人格成立
- [ ] 核心反差成立
- [ ] 说话方式明确
- [ ] 与陌生人、熟人、群体、独处时的状态明确
- [ ] 与镜头关系明确
- [ ] 内容母题明确

## 服装
- [ ] 服装公式明确
- [ ] 版型规则明确
- [ ] 色彩规则明确
- [ ] 图形规则明确
- [ ] 单品库完整
- [ ] 至少 4 类衣柜人格成立

## 角色卡
- [ ] 主角色卡完成
- [ ] 三视图完成
- [ ] 正背面结构一致
- [ ] 身高、肩宽、腰臀比例一致
- [ ] 近景与全身身份一致

## 世界观
- [ ] 世界一句话成立
- [ ] 世界边界明确
- [ ] 至少 5 个固定地点
- [ ] 至少 4 个固定居民
- [ ] 异常尺度明确
- [ ] 世界能持续产生小故事

## 视觉统一
- [ ] 相机体系明确
- [ ] 镜头焦段感明确
- [ ] 日间协议明确
- [ ] 夜间协议明确
- [ ] 肤色、高光、阴影、颗粒、白平衡明确
- [ ] 图片与视频属于同一个摄影世界

## 回归验证
- [ ] 3 套服装通过
- [ ] 3 个场景通过
- [ ] 3 个时间通过
- [ ] 3 个表情通过
- [ ] 至少 1 段视频通过
- [ ] 陌生观察者能判断为同一个人

## 失败规则

只要以下任一情况出现，不得标记 `v1.0`：

- 换装即换脸
- 夜景明显增龄或减龄
- 动态时身份崩溃
- 只能靠发色、耳机、帽子等外部符号识别
- 世界观比人物本身更有存在感
- 对标痕迹强到能一眼指出具体来源
