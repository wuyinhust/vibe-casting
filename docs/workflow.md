# Vibe Casting 工作流

## 总览

```text
找对标
→ 灵感迸发
→ 视觉迭代
→ 人设确认
→ 身份锚点
→ 服装体系
→ 角色卡生成
→ 世界观生成
→ 视觉统一
→ 回归验证
```

## 阶段门槛

### 1. 找对标
只有当“可抽象继承的机制”与“禁止复制的具体符号”都写清楚后，才进入下一阶段。

### 2. 灵感迸发
至少形成 3 个独立方向。禁止用一张图里塞 3 个角色代替真正比较。

### 3. 视觉迭代
脸、年龄、发型、动态未稳定前，不进入大规模服装与世界设计。

### 4. 人设确认
必须能回答“看起来 ___，实际上 ___。”否则核心反差仍不够清晰。

### 5. 身份锚点
必须明确一级、二级、三级锚点，并证明角色不是靠固定服装被认出。

### 6. 服装体系
至少建立版型、色彩、图形、单品库和 4 类衣柜人格。

### 7. 角色卡生成
主角色卡与三视图用途不同，两者都应产出。

### 8. 世界观生成
世界应是角色的故事机器，而不是设定百科。优先建立有限空间、固定地点、固定居民与异常尺度。

### 9. 视觉统一
把“电影感”“胶片感”等抽象词拆成相机、镜头、色彩、高光、阴影、颗粒、白平衡、日夜协议。

### 10. 回归验证
随机换服装、场景、时间、表情并生成视频。通过后才能标记 v1.0。

## 推荐版本里程碑

- `v0.1`：灵感阶段
- `v0.3`：脸开始稳定
- `v0.5`：人格成立
- `v0.7`：服装体系成立
- `v0.8`：角色卡成立
- `v0.9`：世界与摄影成立
- `v1.0`：图片与视频一致性测试通过

## 核心判断

Vibe Casting 的最终目标不是生成最漂亮的那个人，而是找到那个：

> 换衣服、换地方、换光线、换镜头、开始运动之后，仍然会被认出来的人。
