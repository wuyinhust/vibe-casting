# Examples

本仓库默认不提供任何固定角色案例。

原因很简单：

Vibe Casting 的目标是复用**角色生成方法**，而不是让新角色无意识继承某个示例人物的：

- 脸
- 发型
- 发色
- 服装
- 道具
- 性格反差
- 内容母题
- 世界观
- 摄影风格

如果你使用本 Skill 完成了自己的角色，可以把角色项目放在这个目录中作为你自己的案例归档；但任何案例都不应被视为默认模板。

推荐每个案例至少包含：

```text
examples/<character-name>/
├── README.md
├── persona.md
├── identity-anchors.md
├── wardrobe.md
├── world.md
├── visual-bible.md
└── regression-report.md
```
